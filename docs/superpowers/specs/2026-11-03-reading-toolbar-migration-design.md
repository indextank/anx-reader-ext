# 阅读页工具入口迁移设计

日期：2026-11-03
状态：已确认
目标页面：书籍阅读页

## 背景与目标

当前阅读页的顶部 AppBar 与底部五按钮工具行由同一个 `Offstage` 控制。底部工具行同时承载目录、笔记、阅读进度、主题和朗读入口，以及笔记、进度、主题、朗读的内容面板。

本次改造移除常驻底部工具行，将用户指定的四个功能入口迁移到顶部，并保留现有业务功能。点击顶部入口后，笔记、主题和朗读仍通过按需底部面板呈现；常态阅读界面不再出现底部工具按钮行。

## 已确认范围

- 目录按钮放在顶部最左侧，位于返回箭头之前。
- 笔记、主题、朗读按钮放在顶部右侧，位于 AI 对话按钮之前。
- 删除阅读进度按钮及其上一章、进度滑块、下一章面板，不迁移到其他位置。
- 删除底部工具行及其显示逻辑，不增加新的底栏显示开关。
- 保留点击阅读区、键盘和鼠标悬停等现有顶部栏唤出方式。
- 保留独立的右下角 TTS 播放悬浮条及其当前未提交开发内容。
- 保留笔记、主题、朗读的实际业务服务、配置项和 AI 按钮显示条件。
- 不修改首页底部导航、系统状态栏、鼠标悬停等名称相近但用途不同的设置。

## 方案选择

采用方案 A：按需底部面板。

- 常态只有顶部栏，没有底部工具行。
- 点击笔记、主题或朗读后，显示对应的底部内容面板。
- 面板不再附带五按钮行，也不包含阅读进度面板。
- 相比桌面弹层或居中对话框，此方案最大限度复用现有组件和交互，改动集中，移动端与桌面端行为一致。

## 顶部布局

### 宽屏顺序

左侧：

1. 目录
2. 返回
3. 书名，单行显示，空间不足时省略

右侧：

1. 笔记
2. 主题
3. 朗读
4. AI 对话，仅在 `EnvVar.enableAIFeature` 为真时显示
5. 复制章节
6. 书签
7. 书籍详情

目录和返回通过自定义 leading 区域实现，确保目录位于返回之前。新增按钮沿用现有 `AppIconButton` 和原图标，并提供本地化 tooltip；不引入新的视觉样式或业务开关。

### 窄屏与可访问性

- 书名保持单行省略，不挤压按钮到布局之外。
- 宽屏保持单行 AppBar；空间不足时使用双行顶部区域：第一行保留目录、返回和书名，第二行放置可横向滚动的操作区。
- 是否使用双行由实际可用宽度决定，不以平台类型决定；所有指定按钮保持可访问。
- 使用现有设计系统间距和尺寸 token，不新增硬编码样式。
- 在窄屏及放大字体条件下验证无横向溢出，按钮 tooltip 和语义标签可用。

## 面板与状态管理

### 状态边界

保留当前控制整组阅读 Chrome 的内存显隐状态，但将其语义收敛为“顶部栏及按需功能面板是否隐藏”。该状态不是持久化偏好，不新增 Prefs key。

将“当前功能面板”限定为以下状态：

- 无面板：只显示顶部栏和遮罩。
- 笔记面板：显示 `ReadingNotes`。
- 主题面板：显示 `StyleWidget` 或其内部子页面。
- 朗读面板：显示 `TtsWidget`。

阅读进度不再是可选面板状态。

### 打开与关闭

- 目录：调用现有目录抽屉逻辑，打开前隐藏阅读 Chrome。
- 笔记：设置笔记面板并显示底部内容区。
- 主题：异步加载主题后显示主题面板；加载期间显示现有骨架或加载状态，失败时在面板内显示可重试错误状态，且始终可通过遮罩关闭。
- 朗读：显示 `TtsWidget`，保留 `TtsSessionGate` 的初始化、失败和重试行为。
- 点击阅读区遮罩或执行现有隐藏菜单操作：同时关闭当前面板和顶部栏。
- 再次唤出菜单：默认不自动恢复上一次已关闭的面板。
- 切换笔记、主题、朗读入口：替换当前面板内容，不叠加多个面板。

### 主题内部导航

现有 `StyleWidget` 通过 `setCurrentPage` 切换背景选择等子页面。迁移后该回调直接更新阅读页面板状态，不再依赖 `BottomSheet` 内部的 `StatefulBuilder`。主题变更继续调用现有 Prefs 和 `EpubPlayerState` 方法。

### 阅读器焦点与 TTS 悬浮条

- 保留阅读 Chrome 显示时释放阅读器焦点、隐藏时恢复焦点的逻辑。
- 保留 Linux CEF 的键盘焦点处理。
- TTS 播放悬浮条仍只在阅读 Chrome 隐藏时挂载，避免与顶部栏或按需面板重叠。
- 不修改 `tts_fab.dart`、TTS 引擎或倍速相关未提交代码。

## 删除边界

- 从 `reading_page.dart` 删除底部五按钮行、进度分支和不再使用的导入。
- 删除 `lib/widgets/reading_page/progress_widget.dart`，因为 `ProgressWidget` 与 `ProgressDisplay` 仅由该入口使用。
- 保留 `EpubPlayerState.goToPercentage()`、章节导航和正文页脚进度显示；这些能力仍可能由目录、键盘、滚动或其他阅读逻辑使用，不属于本次死代码清理范围。
- 不删除任何现有 Prefs 设置或同步 catalog 条目，因为五个底部按钮没有各自独立的业务显示开关。

## 组件职责

- `ReadingPageState`：管理阅读 Chrome 显隐、当前按需面板、顶部按钮顺序及目录抽屉。
- `ReadingNotes`：继续负责阅读页笔记列表，不感知顶部入口布局。
- `StyleWidget`：继续负责阅读样式和内部子页面，仅调整面板切换回调的宿主。
- `TtsWidget`：继续负责朗读会话与控制，不感知顶部入口布局。
- `TtsFab`：保持独立，继续负责播放、暂停、倍速和停止快捷控制。

## 错误处理

- 主题加载失败：在按需面板内显示错误状态和重试入口，允许通过遮罩关闭，不阻塞阅读页。
- TTS 初始化失败：保留 `TtsSessionGate` 错误状态和重试入口。
- 面板内容为空或阅读器尚未就绪：沿用各组件现有防护，不为本次 UI 迁移扩大业务重构。
- 窄屏或字体放大：通过可滚动操作区和书名省略避免溢出，不隐藏指定功能。

## 测试与验收

### 自动化测试

优先将顶部 Chrome 和按需面板宿主拆成可测试的小型组件，避免在组件测试中启动真实 WebView、数据库和音频插件。覆盖：

1. 顶部按钮的左右顺序，目录位于返回之前，笔记／主题／朗读位于 AI 之前。
2. 常态不存在底部五按钮行和阅读进度入口。
3. 点击笔记、主题、朗读分别显示正确面板，且面板中没有工具按钮行。
4. 目录按钮触发现有目录回调；返回和 AI 条件显示不回归。
5. 隐藏阅读 Chrome 时清理当前面板，再次显示不自动恢复旧面板。
6. 主题内部 `setCurrentPage` 能替换当前面板，无需 BottomSheet 的 `StateSetter`。
7. 320×640 及 1.3 倍字体下无布局溢出，空间不足时使用双行顶部区域，所有操作仍可通过横向滚动访问。
8. 现有阅读笔记、主题、TTS SessionGate、目录和 TtsFab 测试继续通过。

### 人工验收

- 打开书籍并唤出菜单，顶部顺序符合设计，底部没有常驻工具框。
- 目录、返回、笔记、主题、朗读、AI、复制章节、书签和详情均执行原功能。
- 笔记、主题、朗读面板可打开、切换和关闭；主题背景子页面可进入和返回。
- 阅读进度面板及其按钮不再出现，正文页脚百分比仍正常。
- TTS 播放或暂停时，隐藏阅读 Chrome 后右下角播放悬浮条仍可用。
- 宽屏、窄屏和字体放大时无按钮溢出或书名异常换行。

## 非目标

- 不重新设计阅读页配色、图标或面板内容。
- 不改变 AI 对话的展示模式。
- 不删除 TTS 播放悬浮条或修改其未提交功能。
- 不清理与本次入口无直接关系的阅读器 API、Prefs 或同步设置。
- 不顺带修改设置页或其他未提交工作。
